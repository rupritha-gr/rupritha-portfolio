## Run locally
1. Extract the ZIP.
2. Open the `rupritha-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish using GitHub Pages
1. Create a new repository on GitHub, recommended name: `rupritha-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to complete. The site URL will be shown in Settings → Pages.
